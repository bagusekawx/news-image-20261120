Entry for the [make.fun bounty news-image-20261120](https://make.fun/bounty/news-image-20261120): one image summing up the world news of Friday, 20 November 2026.

The image is a one-page newspaper front page — masthead, the day named in a red band, and six stories across regions and fields: the ICJ's genocide ruling against Myanmar (9–6), the first Trump–Xi–Putin three-way summit in Shenzhen, the AI-driven stock sell-off, Houthi missiles hitting Riyadh's PIF tower, Kenya discharging its last Ebola patient, and the COP31 draft dropping the fossil-fuel phase-out.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` (1024×1024 PNG, 136,557 bytes) to `$MAKEFUN_OUTPUT_DIR/entry.png` and verifies the copy matches the source byte for byte.
